# Planejamento de Manutenção de Escadas Rolantes

## Descrição

Projeto acadêmico desenvolvido para simular o monitoramento
e o planejamento de manutenção de escadas rolantes,
utilizando dados de sensores e algoritmos de otimização.

## Tecnologias

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Funcionalidades

1. Cálculo de degradação acumulada.
2. Recursão simples, memoização e tabulação.
3. Modelagem da rede de estações com grafos.
4. Busca em largura (BFS).
5. Caminhos mínimos com Dijkstra.
6. Busca heurística com A*.
7. Planejamento de turnos de manutenção.
8. Análise comparativa de desempenho.

## Como executar

1. Instalar Python e Jupyter Notebook.
2. Instalar as bibliotecas necessárias:

   pip install pandas matplotlib jupyter

3. Disponibilizar os arquivos CSV utilizados pelo projeto.
4. Abrir o notebook no Jupyter.
5. Executar as células na ordem apresentada.

## Dados utilizados

O projeto utiliza dados simulados de sensores de escadas
rolantes, associados às estações da Linha 4-Amarela.

Os tempos de deslocamento e de manutenção são estimativas
acadêmicas e não representam necessariamente dados
operacionais reais.

## Resultados

Os resultados são exportados para a pasta `resultados`,
nos formatos CSV e JSON.

## Objetivo

Demonstrar como algoritmos de programação dinâmica,
busca em grafos e planejamento podem contribuir para
a priorização de manutenções e a análise de dados.
